# 批量与文件夹导入 · 0.3.1

进入「教材书架」，点击「导入文件夹」选择教材目录，或把文件夹拖到导入区域；也可以「批量选择文件」。会读取子文件夹，无每次五本的数量限制。

支持 PDF、DOCX、TXT、MD，单本最大 50 MB，PDF 最多 1500 页。其他格式、空文件和过大文件会跳过并说明原因，不会打断整批导入。压缩包请先解压；老式 DOC 可另存为 DOCX。扫描 PDF 会在本机 OCR，所需时间取决于页数。

文件逐个传输、逐本解析，避免同时解析大量教材占满内存。传输完成前请保留页面；可暂停或继续传输。已上传的解析队列保存在本机，重启软件后继续处理，正在解析的那一本会重新解析。还没上传的文件需要重新选择；相同内容的教材会自动去重。

传输失败可点击「重试失败传输」；解析失败可在书架点击「重试解析」。处理进度会显示入库、排队、重复、跳过与失败数量。详细队列最多显示 100 条，全部文件仍会处理，解析结果在书架查看。

导入后，在「学习计划」选择要用于这门课的教材并生成计划。往书架添加新书不会自动改写已经生成的课程计划。

教材构成可检索、可引用的本地资料库，并非重新训练底层模型。上课时会把相关片段交给你选择的模型；云端模型会收到这些片段。
