# 读书伴读

打开学堂，点击左侧「读书伴读」，也可直接打开 http://127.0.0.1:32194/study?mode=reading 。

1. 填写正在阅读的书名，作者／版本可选。纸质书、外部阅读器可以只填书名；已经导入的书可以关联本机书架。
2. 点击「开始这次伴读」。可填写章节／页码、粘贴当前段落，也可以从已导入书籍中逐段选择原文。
3. 开启连续语音，停顿后自动发送，也可以使用文字或系统输入法。老师先解释问题，再给类比或应用例子；默认不要求参加任何考试。
4. 语音转写、问题、老师回答以及当时的阅读位置、选段和检索原文自动保存在本机。回答中断或失败会标明状态。
5. 点击「整理本次阅读」可继续读，点击「结束并整理」结束本次。整理包含真实问题清单、讨论摘要、待核实内容、AI延伸例子与自测问题、相关词句、下次阅读建议。
6. 历史记录可以继续伴读。已有整理后产生新对话，会提示更新。每次可导出 Markdown，包含完整原始交流和来源；模型不可用时仍能导出原始记录或仅结束保存。

书名本身不等于这本书的全文，具体版本、页码、引文应提供原文核对。只有当前关联书籍会参与本机检索；只发送当前相关片段与短期交流上下文给当前选用的模型。选中本机原文位置后，自动检索不会添加更靠后的片段；对纸质书手填页码无法自动保证无后文内容，请提供当前选段。不会自动读取外部阅读器或监听系统屏幕。

记录保存在当前课堂的 SQLite 数据库，不上传到 GitHub。问答和AI整理仍需要已配置的模型连接；原始记录保存与导出不需要额外模型调用。每10次发言分批整理，结果缓存，未新增交流时复用。

## 设计参考

仅参考公开功能与交互思路，本次独立实现，没有复制以下项目源码或引入它们的运行依赖。

- [Marginalia](https://github.com/eddmann/Marginalia)：书籍与章节上下文、书内对话持久化。
- [Readest](https://github.com/readest/readest)：原文选取、阅读位置和批注导出。
- [Crossbill](https://github.com/Crossbill-App/crossbill-web)：把阅读内容整理成笔记、主动回忆和复习素材。

本功能独立于每日60分钟课程、考试课程和游戏伴读，不会把读书交流算作完成考试任务。

本次更新也将中文朗读的官方 Edge TTS 组件升级至 7.3.1，以修复旧版连接返回403的问题，保留已选声线、音调与亮度。英文仍使用原有本机声线，中文需要在线连接。
