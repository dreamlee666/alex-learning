# Alex 通用学习课堂：Windows 免费分享版

1. **先把整个 ZIP 解压**到自己的普通文件夹，例如桌面；不要在压缩包内启动，也不要只复制 EXE。
2. 双击 **Alex-Learning.exe**。不用安装 Python，不需要管理员权限。首次启动会从官方来源下载经过 SHA256 校验的 FFmpeg、eSpeak NG 和微软 C++ 运行组件，放在软件自己的目录里；速度取决于网络。以后不重复下载。
3. 点击 **账号与声音设置**，连接自己的 ChatGPT 账号并完成官方套餐授权和模型测试，然后回到课堂。能否使用与额度以账号授权结果为准。软件免费，模型服务和账号套餐由使用者自行承担。登录授权保存在当前 Windows 用户的加密存储里，不与其他人共用。
4. 课堂页面允许麦克风后即可练习。也可以用输入法转写后粘贴、编辑文字。教材书架支持本机文件导入；按主题建立独立课程，设置教学模式、语言和基础，再生成计划；可以切换已保存的课程。旁边小黑板显示学习文字和来源。SQE 与英语练习是可选模式，也可以学习其他学科。没有随包附赠商业教材。

## 打开与退出

- 双击软件后自动打开浏览器里的课堂。保留启动窗口；点击“停止课堂”或关闭启动窗口会停止本软件的本地服务。
- 便携版使用 32193 / 32194 / 32195 三个本地端口。与原开发版的 12393 / 12394 / 12395 独立；一次只能运行一个便携版。
- 可以移动整个软件文件夹；不能只移动 EXE。运行环境路径会在下一次启动时自动更新。
- 语音识别和英语语音在本机计算；模型对话需要联网。中文语音使用联网的 Edge TTS。没有账号授权时仍可查看资料、设置和学习空间，不能得到模型回答。
- 建议 Windows 10/11 64 位、8 GB 以上内存。此版本语音默认使用 CPU，不要求 NVIDIA 显卡。

## 数据在哪里

- 账号授权、书架与学习计划：`%LOCALAPPDATA%\SQEEnglishTutorPortable`；授权使用 Windows DPAPI 加密。
- 当前会话记录与服务日志：软件文件夹的 `App\chat_history`、`App\logs`、`App\deployment`。
- 若用过后再分享，请分享原始发布 ZIP。不要重新压缩已经使用的文件夹，以免带入自己的会话、教材或本地访问密钥。
- 删除软件文件夹不自动删除用户资料；若需要完全卸载，先停止软件，再自行删除上述独立资料目录。

## 故障处理

- 第一次下载失败：检查网络或系统代理后重试。固定来源和 SHA256 在 `launcher\downloads.json`，软件不会运行校验失败的文件。
- 模型无法连接：在“账号与声音设置”重新测试网络、授权和模型；浏览器与模型服务可能有不同的网络可达性。
- 端口被占用：先关闭另一份便携版；软件不会强行结束其他程序。
- 启动失败：点击“查看日志”，查看 `server.stderr.log` 或 `initialize-error.log`。向别人提交日志前先检查是否包含自己的学习内容。
- 当前 EXE 未签名，Windows 可能提示未知发布者。请核对来源；不要关闭系统安全防护。

## 换学科或教材

在书架导入新资料 → 每日学习计划的课程选择器选“创建新课程” → 填主题（如 Python 入门、世界历史）→ 默认选择“通用学习” → 选教学语言、基础和新教材 → 生成计划 → 选择一节课。以后更新教材时，在新课程中选择新版本即可，不需要修改软件代码。

旧课程、完成记录和笔记保留，可在课程选择器切回。切换课程会另开课堂会话，避免上一学科的讨论影响新课程；历史文件仍保留。语言练习需选择“英语练习”，考试准备需选择相应 SQE 模式。

## 更自然的语音对话

默认关闭发送前的转写确认，默认启用连续语音对话。点一次麦克风，说完停顿后自动提交，老师播放完回复后继续听。再点麦克风结束。可把停顿设为 1.2、2 或 3.5 秒；思考较多时选较长间隔。开启“发送前校对转写”才会逐句要求确认。老师说话期间暂停收音处理，避免把扬声器声音当作你的下一句话。切到其他页面或断开连接会停止麦克风。
