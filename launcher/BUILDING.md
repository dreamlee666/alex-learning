Build from the existing source deployment using deployment/packaging/build_portable.py. Install the recorded main and voice requirements into their separate environments and obtain the pinned model revisions. Run with the main environment Python. The builder copies a whitelist, excludes state, bundles Python from sys.base_prefix, and compiles Launcher.cs with the Windows .NET Framework compiler. --zip creates the clean release archive. The bundled App directory is the corresponding classroom source; the upstream frontend build is available from Open-LLM-VTuber/Open-LLM-VTuber-Web.
