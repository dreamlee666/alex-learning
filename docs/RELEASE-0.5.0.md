# v0.5.0 · 文档伴读与学习记忆

PDF 阅读与现有人物、连续语音进入同一课堂。翻页和选段同步老师上下文，高亮、批注及阅读位置持久保存；原有文本和纸质书伴读继续可用。

阅读整理可核对后加入当前课程的 FSRS 复习，并在每日任务中查看到期内容。没有回答的问题不生成参考答案，不自动增加课程完成进度。另有无需模型的原始交流整理。

新增内容理解与英语表达分别反馈、Obsidian 自动导出和相关笔记关键词检索、私人学习数据备份。狭义单词解释在同一原文和配置下缓存；案例分析、比较和作文批改继续调用模型。

使用自有模型来源。此次不包含作者教材、个人笔记、账号或 API 密钥。图表视觉推理、发音评分、外部 PDF 批注双向同步仍未实现；冷启动问答速度取决于模型和网络。

详细步骤见 [文档与学习记忆说明](../App/deployment/WORKSPACE-GUIDE.md)。
