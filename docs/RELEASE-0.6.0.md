# v0.6.0：语义知识库、每日调整与回答分流

教材关键词不一致时，原来的检索容易找不到相关段落。本版增加本机中英多语种向量检索，与现有关键词检索合并排序，并显示原文、位置和来源。阅读时限定当前书，个人笔记单独标注，不能替代权威教材。

## 怎么使用

1. 打开「读书伴读」，在「本机语义知识库」建立当前教材或全部书架索引。首次下载约135MB固定版本模型，校验后使用CPU计算；没有索引仍可用关键词检索。索引在后台进行，已完成部分可用，重复索引复用未变化内容。
2. 在「今日60分钟」完成实际回忆和练习，也可用当天英语产出点击「用这次产出检查内容与英语」。系统分别反馈知识理解与英语表达，诊断要求引用真实输入。
3. 下次打开当天任务时，根据近期14天的独立复习卡、选择题和诊断重新分配时间。证据不足保持基础安排；重复提交同一题不会增加独立样本。阶段检查保留原计时，不自动完成课程或跳课。

## 响应优化

狭义词义只传当前词附近的必要原文与少量历史，保留来源编号；比较、推理、案例和写作任务保留完整任务上下文。对明确支持的GPT-6系列，词义使用低推理强度，复杂问题使用高推理强度，其他兼容服务沿用原参数。本机原文、已有精确词句与相同上下文的成功缓存继续直接返回；缓存命中有标注。

文字首段速度不等于整句语音速度，仍受模型、网络、转写和合成影响。不承诺所有问题即答。

## 验证

- 111项Python检查和12项JavaScript检查通过；前端脚本语法通过。
- 实际本机模型已验证中文“信件什么时候算接受”能检索到英文教材的 Mailbox Rule 段落及页码，热查询一次为13ms。单个示例不能代表所有材料的检索准确率。
- 一次无缓存词义请求的文字首段为3.55秒，完整文字6.349秒；不含语音识别和合成，不作为稳定延迟承诺。
- 使用独立测试资料调用真实模型：能将错误的概念理解与英语语法分别反馈，形成总计60分钟的巩固安排；没有写入正式课程或自动完成任务。
- 发行包逐项比对公开源文件，并检查私人数据库、凭证、运行配置、日志及作者本机路径；发布校验报告与SHA256。

## 数据与限制

升级保留账号配置、教材、课程、复习和声音，安装前备份数据库。向量和诊断保存在本机；向云模型提问时仍会发送必要教材片段和你提交的产出，详见[隐私说明](../PRIVACY.md)。公开模型权重不随发行包分发，首次启用时单独下载。

自评、AI练习答案和AI诊断均有误差，不是官方考试评分或通过预测。语义检索可能遗漏；没有实现图表视觉推理、音素级发音评分或外部PDF批注双向同步。第三方付费API未逐一使用真实密钥测试。
