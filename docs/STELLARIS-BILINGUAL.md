# 群星游戏内中英双语界面

这次是安装在群星里的本地文字 MOD，不依赖截图、OCR 或 AI 调用。

## 启用

1. 打开 Steam 群星的 Paradox 启动器。
2. 在「所有已安装的 MOD」中找到 **Alex English + Chinese · 双语学习界面**。如果没出现，完全关闭启动器再打开。
3. 把它加入你实际使用的「播放集 / Playset」，打开启用开关，拖到 MOD 列表靠后位置，让双语文本与字体在其他汉化、字体 MOD 之后加载。没有自动改你的播放集和现有 MOD 开关。
4. 游戏语言保留 English 即可，本 MOD 给英文模式加入游戏自带的中文字体。也生成了简体中文模式下的双语文本。
5. 从这个播放集启动游戏；如果游戏已经在运行，需要退出再启动，热加载不会生效。

## 显示方式

- 短名称、按钮：英文（中文），例如 Upkeep（维护费）。
- 较长说明、事件：英文正文，然后中文正文。
- 动态国家名、数值、图标、颜色及参数格式保留。英文和中文使用独立文本引用，防止嵌套引用反复追加译文。
- 格式片段、纯变量字符串和没有对应中文的文本不强行拼接。

## 更新与还原

游戏或 MOD 更新后，运行生成器（`python App/deployment/stellaris_bilingual.py`，Python 3.10+，无第三方依赖）。它读取当前安装和上一次启动记录的启用 MOD，按记录顺序合并。有新的播放集时，先正常启动一次游戏再重建，确保读取的是实际启用列表。

想恢复原来的界面，在播放集中关闭本 MOD 即可；不修改群星安装文件或存档。生成器会覆盖自己生成的文件，不会删除其他 MOD，也不会改 dlc_load.json。

## 目前的验证范围

已检查 UTF-8 BOM、本地化行格式、参数与静态引用、生成的中文字体规则，并通过三个生成器测试。**尚未在运行中的群星界面确认渲染和排版**。双语文本会占用更多空间，窄按钮、舰船名称和长事件可能截断或变高。若有乱码、缺字或文字遮挡，可先禁用本 MOD，保留原有界面。

当前生成包含本体及启用列表中可读取的 MOD 的中英文文本，不保证所有 MOD、动态自定义名称都有中文。这里的完整游戏和 MOD 文本仅供你本机使用，不加入公开的软件分享包。

参考项目：https://github.com/cloudwu/stellaris_cn （借鉴汉化 MOD 和中文字体使用方式，未下载其翻译文本。）
