# v0.7.0：扫描页取词、图表提问与批注导回

旧版PDF页面只有原生文字可选，模型接收的是提取文字，无法真正看到图表。本版补上明确的当前页图像请求，并让扫描页也能划线和取词。

## 新增功能

- **扫描页取词（本机）**：为当前页建立可选择的OCR文字层，按页缓存，可继续高亮、批注、解释选段。OCR不上传页面，可能出现错字和位置误差。
- **发送本页给视觉模型**：输入图表问题后主动发送当前页图像，需当前模型支持图片输入。结果保存为AI解释，标明页码；之后可语音继续讨论，或点击「让老师继续讲解看图结果」。不会自动读取屏幕或发送整本书。
- **导回外部PDF批注**：选择同一教材的批注PDF，核对页数、旋转、文字和页面渲染内容后导入。支持高亮、下划线、删除线和文字批注，统一显示为课堂标记。重复跳过；冲突保留两份，不覆盖原记录。原PDF不被替换，外部删除不会删除课堂批注。上限50MB、5000项。

文档处理时暂停切换和新对话入口，避免问题绑定到错误页面。连续语音正在录音时先结束录音，再执行这些操作。

## 验证

123项Python检查、12项JavaScript检查及前端语法检查通过。覆盖同版PDF导回、不同页面/旋转拒绝、重复导入、批注冲突保留、导出再导入、OCR缓存、图像请求需主动操作、模型失败不保存半截解释。

真实模型与本机OCR使用独立临时资料测试：自编扫描柱状图中，OCR识别出年份和数值，所配置视觉模型正确读取2024年的10、2025年的15，并将增长计算与图中未给出的原因区分。测试不写入正式课程；一个图表示例不代表所有材料的准确率。

本版保留0.6.0的语义知识库、按证据调整每日60分钟、回答分流，以及原有账号配置、声音、教材、复习和Obsidian。发行包包含SHA256、公开源文件比对及隐私检查报告。

## 边界与隐私

图像解释可能误读细小数字、复杂排版和图表；OCR也需核对。第三方视觉服务未逐一使用真实密钥验证。不支持图片的模型仍可使用文字课堂和本机OCR。音素级发音评分、自动同步外部批注删除尚未实现。

批注导回是保留历史的主动合并，不是后台监视或自动镜像。重新导出遇到已有外部修改时保留原文件，另存更新副本。详见[操作说明](../App/deployment/WORKSPACE-GUIDE.md)与[隐私说明](../PRIVACY.md)。

图像请求按[OpenAI官方图片输入协议](https://developers.openai.com/api/docs/guides/images-vision)实现；其他模型使用兼容的Chat Completions图片内容格式。OCR复用现有RapidOCR，PDF处理复用现有PyMuPDF，没有增加新的运行依赖。
